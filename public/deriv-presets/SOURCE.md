# Deriv DBot preset XML

The XML files in this directory are sourced from Deriv's MIT-licensed
`trading-bot-template` repository:

https://github.com/deriv-com/trading-bot-template/tree/master/src/xml

They are imported as editable starting points, not as a promise of profit or
suitability. Operators must review stake, stop-loss, and risk settings before
running anything on a demo account. See `LICENSE` for the MIT licence.
