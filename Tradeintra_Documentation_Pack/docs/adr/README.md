## Template

1. **Title**
2. **Status:** Proposed / Accepted / Rejected / Superseded
3. **Date**
4. **Context:** What problem are we solving?
5. **Decision:** What did we choose?
6. **Alternatives:** What else was considered?
7. **Consequences:** Trade-offs, costs, risks, and operational effects.
8. **Security/privacy implications**
9. **Revisit trigger:** What evidence would justify reconsidering it?
